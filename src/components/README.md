# Shared Components

Folder `components/` dipakai untuk komponen reusable lintas feature.

Subfolder yang mulai kita standarkan:

- `ui/`: primitive UI umum
- `forms/`: wrapper field, form shell, helper validasi visual
- `tables/`: table shell, column helpers, empty/loading state tabel
- `layout/`: komponen layout reusable MorrusPOS

Komponen lama dari TailAdmin masih dipertahankan sementara untuk referensi.
