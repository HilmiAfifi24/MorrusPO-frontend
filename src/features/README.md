# Features Layer

Setiap folder feature mewakili domain bisnis MorrusPOS.

Struktur minimal yang disarankan di dalam tiap feature:

```text
feature-name/
├── api/
├── components/
├── hooks/
├── pages/
├── schemas/
├── types/
└── index.ts
```

Template TailAdmin lama belum dipindahkan ke sini. Folder ini adalah fondasi migrasi bertahap.
